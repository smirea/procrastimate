# Recurring tasks

- **Completing moves the task.** Checking off a recurring task moves its due date to the next occurrence instead of closing it. It stays in its list with the new date, and an undo toast reads `Completed "<title>", next due <date>`. Undo restores the previous date and reminders.
- **Next occurrence.** The next date is the first one after today, stepping whole intervals from the current due date. A weekday set steps to the next listed day of the same week, and after the last listed day to the first listed day of the week `interval` weeks later. Weeks start on Monday. A due date moved off the set steps to the next listed day after it. Completing early moves one interval. Completing an overdue task skips the missed occurrences instead of leaving it overdue. A recurring task with no due date counts from today. This matches Todoist's `every`. Todoist's `every!`, which counts from the completion date, is not supported.
- **Months clamp.** A monthly repeat on the 29th to 31st lands on the last day of a shorter month, and every later occurrence counts from that clamped date, so a repeat on the 31st becomes a repeat on the 28th after February. That holds whether the task is completed on time or overdue: Jan 31 completed on Mar 1 skips Feb 28 and lands on Mar 28, the same date on-time completions reach. A yearly repeat on Feb 29 becomes Feb 28 the same way. Keeping the original day, as Todoist does, would need a stored anchor that every due date edit keeps in sync, which is not worth a field yet.
- **Reminders follow.** Relative reminders follow the new due time on their own. Absolute reminders shift by the same number of days as the due date, which for a weekday set varies with the gap to the next listed day. Each one fires once when its new time comes, like any reminder. The new due time notifies on its own too, because a due time is a reminder.
- **Editing.** The repeat chip in task details sets a preset (every day, weekday, week on the due weekday, month, or year), a custom interval, a weekday set, or `Don't repeat`. A row of seven weekday toggles, Monday first, at the top of the menu, edits the set and keeps the menu open. A plain weekly repeat starts the set from its due weekday. Any other repeat, or none, starts an empty set, so the first toggle makes a weekly repeat on that day. The last selected day cannot be turned off, so clearing goes through `Don't repeat`. A set of one day is stored as a plain weekly repeat on that day, the same shape `every fri` parses to, so the `Every Fri` preset shows as selected. A custom weekly interval keeps the set. The due date moves to the first listed day on or after the due date the menu opened with, so toggle order never changes the result. Setting a repeat on a task without a date dates it today, and removing the date removes the repeat, because a repeat needs a date to count from. Typing a repeat into the title replaces the current one.
- **Display.** Rows show a repeat icon next to the due date. Upcoming shows only the next occurrence. A weekday set reads `Every Mon, Wed, Fri`, Monday first, or `Every 2 weeks on Tue, Thu`.
