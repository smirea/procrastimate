# Settings

- **One place for device and data settings.** A `Settings` row with a gear sits at the bottom of the sidebar, which is also the phone drawer. It stays outside the scrolling area, so it stays put and the settings popover is never clipped. There is no Notifications row.
- **Popover on desktop, sheet on a phone.** On desktop it opens a small glass popover above the row. On a phone it closes the drawer and opens a bottom sheet with a close button, like search, and it never stacks with another sheet. Both show the same panel.
- **Contents.** The `Theme` switch (see Theming), one `Dictation` line, `Quick add buttons`, one notifications line, `Import from Todoist`, `Delete all data`, `Sign out`, and `Delete account`. Dictation is `Native` or `ElevenLabs`, `Native` until changed (see [Ramble](ramble.md)). `Quick add buttons` toggles which attribute buttons quick add's chip row shows; it is the same synced setting as the pins in quick add's `+` menu (see [Quick add](quick-add.md)). The notifications line reads `Notifications: On`, `Notifications: Off`, or `Notifications need permission`. The last one is a button: on the web it asks again, and on iOS it opens system Settings. `Delete all data` confirms, then wipes tasks, projects, and labels on this device and, on the next sync, on the server. `Sign out` drops the session at once and keeps the local document. On the web a refused sign-out signs back in with a toast, since the httpOnly cookie would otherwise sign in again on reload. `Delete account` confirms, then deletes the user and their data. It is not optimistic: it reads `Deleting…` until the server confirms, and a failure is a toast. There is no Sync section and no settings page. Dictation does not get an App Intent: it is a preference, like the theme, not an action on a task.
