# Settings

- **One place for device and data settings.** A `Settings` row with a gear sits at the bottom of the sidebar, which is also the phone drawer. It stays outside the scrolling area, so it stays put and the settings popover is never clipped. There is no Notifications row.
- **Popover on desktop, sheet on a phone.** On desktop it opens a small glass popover above the row. On a phone it closes the drawer and opens a bottom sheet with a close button, like search, and it never stacks with another sheet. Both show the same panel.
- **Contents.** The `Theme` switch, the `Theme color` swatches, and a `Custom` color row (see Theming), one `Dictation` line, `Quick add buttons`, one notifications line, `Import from Todoist`, `Delete all data`, `Sign out`, and the version at the bottom. Dictation is `Native`, `ElevenLabs`, or `Gemini Live`, `Native` until changed (see [Ramble](ramble.md)). `Quick add buttons` toggles which attribute buttons quick add's chip row shows and orders them; it is the same synced setting as the pins in quick add's `+` menu (see [Quick add](quick-add.md)). The shown buttons come first, in row order, and drag to reorder: by a handle on the web (or the arrow keys on a focused handle), and by a long press on iOS. The hidden ones follow in the default order and do not drag, since the row never shows them in a stored order. The notifications line reads `Notifications: On`, `Notifications: Off`, or `Notifications need permission`. The last one is a button: on the web it asks again, and on iOS it opens system Settings. `Delete all data` confirms, then wipes tasks, projects, and labels on this device and, on the next sync, on the server, where emptying the space also drops their history from the log ([Sync](sync.md)). `Sign out` drops the session at once and keeps the local document. On the web a refused sign-out signs back in with a toast, since the httpOnly cookie would otherwise sign in again on reload. On iOS, leaving the account (sign-out or a rejected token) closes any open sheet except a public share link, because sheets present outside the sign-in gate and Settings would otherwise stay up over the sign-in screen. There is no `Delete account`: Stefan removed it, and the server has no route for it. The version line reads `Version <increment>.<yyyyMMdd>` (see [Production hosting](production-hosting.md)). On iOS a `Tabs` row opens the pinned tab list (see [iOS app](ios.md)); the web has no tab bar, so it has none. There is no Sync section and no settings page. Dictation does not get an App Intent: it is a preference, like the theme, not an action on a task. Ramble's parsing mode (`Smart` or `Commands`) is a synced setting too, but it has no Settings line: its only control is the pill in the Ramble drawer, where it matters (see [Ramble](ramble.md)).
