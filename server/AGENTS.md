# API server

- `src/api.ts` exports one fetch handler for `/api/*`. `src/index.ts` serves it with Bun in development through `src/dev-server.ts`, and the Cloudflare Worker runs it in production through `src/worker.ts`, which wraps it, the crons, and the `Ramble` Durable Object in Sentry, so keep `api.ts` free of Bun and Node APIs. Sentry stays in `src/sentry.ts`; feature code calls its `span`, `identify`, and `reportError`. Run `bun run start:server` from the root, or `bun run start` here.
- Every HTTP endpoint is a procedure of the oRPC contract in `../shared/api/contract.ts`. Add or change an endpoint there first, then implement it in `src/router.ts`. `bun run start` regenerates the client types as you save. Only Better Auth's routes, the PowerSync proxy (`/api/powersync/*`), the Ramble WebSocket, the Sentry tunnel, and `PUT /api/images` stay outside the contract. See `docs/decisions/api.md`.
- Every table is in `../shared/db/schema.ts` (`pg-core`), and Better Auth's in `src/db/auth-schema.ts`. Every query goes through Drizzle on a `Db` from `src/db/postgres.ts`: postgres.js in Bun and over Hyperdrive on the Worker, PGlite in tests. After changing the schema, run `bun run db:generate` from the root and commit `drizzle/`. A new synced table also needs an `ALTER PUBLICATION powersync ADD TABLE` migration. `src/db/generated/` is git-ignored and rebuilt by every script; `src/db/migrate.ts` applies the bundle under an advisory lock and refuses a foreign history.
- A request's context is the `App` in `src/app.ts`: env, parsed `Config`, `Db`, Better Auth, and the Ramble route. `src/config.ts` requires `BETTER_AUTH_SECRET`, `DATABASE_URL` or the `HYPERDRIVE` binding, `POWERSYNC_URL`, `POWERSYNC_JWT_PRIVATE_KEY`, and the VAPID pair; `src/index.ts` fills the local stand-ins env-manager leaves empty. Import settings from generated `src/env.ts` in `src/index.ts` only; the Worker has no env reader. Declare server-only secrets in the server scope of the root `.env`; edit values only in root `.env.local` after `env-manager down`, then `env-manager up`. `scripts/secrets.ts` is the only path from env-manager to Worker secrets, GitHub secrets, and `.dev.vars`; it must never print a value.
- Rows change in one place: `applyWrites` (uploads) and `applyAs` (the agent API) in `src/writes.ts` run each `RowWrite` as one single-row statement with the ownership check and the authorship stamps inside it, no transaction or lock, check a guest's write with `guestRefusal` in `shared/scope.ts` against the guest's `access` rows, insert the `log` rows (with the request's client and the client's op id), and recompute `access` (`src/access.ts`) or the push plan (`src/push.ts`) only when a write touched what they derive from. The server never repairs data; readers resolve dangling references with `shared/dangling.ts`. `src/upload.ts` is the wire boundary for `POST /api/upload`; `src/commands.ts` runs the shared store rules on the server over the loaded tree and diffs them into writes, and `src/memo-tasks.ts` writes memo tasks found by source key. `src/space.ts` holds the space's reads, each sized to its caller: `loadTree`, `accessIn` for the caller's standing, and `sightOf` and `seesTask` for which tasks the caller sees. No route loads a whole space. `src/people.ts` names people from Better Auth's `user` table. `src/actor.ts` is the only code that reads sessions and `pm.` tokens into an actor, with a one-minute in-memory cache for session bearers. `src/write-cost.test.ts` pins the statements of each kind of upload and `src/read-cost.test.ts` those of each route that reads a space.
- `src/sync.ts` signs PowerSync tokens and proxies `/api/powersync/*`. `src/ramble.ts` is the transcription session, hosted by `src/ramble-object.ts` on the Worker and by `src/dev-server.ts` in Bun over `src/sockets.ts`; `src/ramble-cassette.ts` is the fake upstream that replays recorded sessions, and `scripts/ramble-latency.ts` measures the real one. Worker bindings are typed in `src/bindings.ts`.
- Tests run on PGlite through `src/test-app.ts` and call routes the way clients do. `bun scripts/sync-smoke.ts` from the root proves a running server against its PowerSync.
